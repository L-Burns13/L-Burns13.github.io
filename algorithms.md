## Appointment Service

This artifact is my Appointment Service from CS 320. It was created in Java and manages appointment information while enforcing rules for appointment IDs, dates, and descriptions.

For the CS 499 enhancement, I added functionality to retrieve appointments in chronological order and search for appointments within a selected date range. I kept the existing HashMap for direct ID-based access and added list-based sorting for date-related operations. I also added JUnit tests to verify the new functionality.
