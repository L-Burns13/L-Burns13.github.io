## Animal Shelter Dashboard

This artifact is my Animal Shelter Dashboard from CS 340. It was created in Python and uses MongoDB to store and retrieve animal shelter records. The dashboard also uses Dash to display records in a data table, chart, and map.

For the CS 499 enhancement, I improved the filtering system by adding controls for animal type, breed, sex, and minimum or maximum age. I also added logic that dynamically builds MongoDB queries based on the selected criteria, validation for invalid age ranges, and safer handling when searches return no matching records.
